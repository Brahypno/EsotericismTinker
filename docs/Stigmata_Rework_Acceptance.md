# 圣痕负面效果改版与人工验收

状态：已按确认方向补充 17 系列独立预兆，等待人工验收。本次未构建、未运行游戏测试，现有 jar 尚未包含本次修改。错误修复基线提交：`1064e87`。

本文描述当前代码中的行为。自动化测试检查状态、触发和生命周期；粒子可读性、声音、眩晕感受与应对窗口由你在客户端验收。

## 1. 公共规则

- 正常工具仍按 `超载 = max(0, 负担 − 容量 − 调律)` 激活后果；保留原来的圣痕、阶段和后果种子。
- 强度与提示共用超载比例：`(0,25%] / (25%,50%] / (50%,75%] / (75%,100%]` 对应轻微、适中、严重、临界，强度 1–4。
- 同一持有者的同系列装备共享 0–100 失控。切换物品不会归零；不同持有者、不同系列互相独立。
- 近战实际命中、箭矢未被盾挡住的命中、采掘完成、护甲受击积累失控。同系列每 10 tick 最多结算一次，涵盖横扫、多重射击和多件护甲。
- 每次行动按强度增加 **8 / 10 / 12 / 14**。吞灭低饱食额外 +8；圣餐无经验额外 +12；圣福伤害村民、盟友或驯养动物额外 +25。
- **接近触发**：50 点起，身边出现所属系列的稀疏异象；60 点起更密，并间隔出现对应主题的低声提示。早期异象与正式预兆采用同一主题的不同密度，按时间出现，不逐次播报行动。
- **70 点开始预兆**。显现 / 异化 / 封缄的预兆持续 **3 / 2.5 / 2 秒**。每个系列有自己的形态、运动方式和声音，见第 4 节。最后一秒异象更密、刷新更快，并加强一次该系列的主题声音。心跳仅属于献祭；紫水晶音色仅属于圣福。
- 正常装备不显示失控数值或文字倒计时；快捷栏上方的精确状态仅在正确持有或穿戴对应系列的超载测试样品时显示。视线下方会有少量短暂粒子，供第一人称察觉危险，不使用全屏闪光、镜头震动或文字播报。
- 预兆期间降低到 **40 点以下**，预兆取消；40 点整不取消。显化后回落至 35 点，并有 **6 秒**冷却；冷却期间仍可积累。
- 显现的攻击与采掘预兆位于目标处；异化与封缄预兆改为持有者当时的位置。护甲的预兆始终位于持有者受击处。预兆位置固定，不随玩家移动。
- 区域型显化可以走出粒子环躲避。吞灭、圣餐、献祭、苦修和六种条件圣痕的显化作用于持有者；仅走出环不能解除，需要平复。
- 区域与召唤系列保留稀疏的固定外缘点，标记原来的 2.5 格预兆范围；主题异象的收紧、上升或扩散不改变作用范围。自身型系列的预兆与爆发跟随持有者，不使用地面圆环暗示可以走出范围躲避。
- 同一主题在高阶段的横向范围更贴近显化中心；实际落点仍按目标 / 自身的公共规则决定。预兆音从显化处传出，距离持有者超过 8 格时补播同音色的低声近身提示。
- 封缄在缺少该系列平复条件时每秒自主 +2。显现、异化的普通系列停用一秒后每秒自然 −6；六种条件系列另有持续的条件规则。
- 未装备的系列每秒 −10；已开始的预兆仍会计时。物品放在普通背包中、护甲拿在手里、工具损坏时，不产生新的装备积累。
- 升举、恶咒、渎秽的区域最多维持 5 秒并逐渐缩小。新版本不再扩散幽匿、不放置火焰方块；旧存档中已经改写的地形不回滚。
- 怨灵每持有者在附近最多 1 只，20 秒后消失。寄生物最多 2 只，15 秒后消失；不钻入方块、不唤醒普通蠹虫。召唤物不掉物品或经验。

### 条件型效果的共同数值

御权、月相、天极、幽渊、圣福、圣绝：满足条件时，伤害与采掘速度 +4% / +5% / +6% / +7%，每件护甲增加 0.25 / 0.5 / 0.75 / 1 点保护值。

条件不满足时先失去收益；失控达到 40 后，伤害与采掘速度降低 3% / 6% / 9% / 12%，每件护甲扣除相同档位的保护值。不再因轻微超载立刻损失约一半伤害，也不再统一定时施加虚弱。

## 2. 测试物品与指令

需要作弊或 OP 2 级权限。无需新配方或资源生成，使用现有匠魂物品制作带 `[临时测试]` 名称的样品。Shift 提示会标明模拟超载。

```mcfunction
/esotericism_tinker stigmata_test kit judgement 3 2
/esotericism_tinker stigmata_test supplies
/esotericism_tinker stigmata_test target
```

第一条发放天谴、封缄、适中超载的剑、镐、长弓和头盔；第二条给面包、箭、经验瓶、水桶、奶桶和鞍；第三条在面朝方向 4 格处生成无 AI、200 生命的卫道士靶子。采用非亡灵目标，方便检验中毒等效果。

| 指令 | 用途 |
| --- | --- |
| `kit <family> <stage> <degree>` | 发放剑、镐、长弓、头盔各一件 |
| `item <family> <stage> <degree> <kind>` | 只发放一种，`kind` 为 `sword / pickaxe / bow / helmet` |
| `pressure <family> <0..100>` | 为当前装备的对应系列设置失控值；设为 0 会取消预兆 |
| `trigger <family>` | 立即进入正常预兆流程，跳过积累与冷却；用于看特效 |
| `status` | 列出已有系列的失控、阶段和预兆剩余 tick |
| `target` | 生成一个测试靶子，不掉落物品或经验 |
| `hit` | 对自己尝试造成 2 点普通伤害，用于护甲受击测试 |
| `supplies` | 发放验收消耗品 |
| `reset` | 清空自身失控、预兆、冷却，移除附近自己召来的怨灵、寄生物和区域 |
| `cleanup` | 执行 reset，并移除自己物品栏、装备槽中的测试样品，以及附近自己创建的靶子 |

完整前缀都是 `/esotericism_tinker stigmata_test`；系列与工具种类支持 Tab 补全。

- `stage`：1 显现、2 异化、3 封缄。
- `degree`：0 无超载对照、1 轻微、2 适中、3 严重、4 临界。
- 测试样品用 `esotericism_tinker:stigmata_test_overload` 模拟超载，不用于校验正常配方的材料容量与调律。
- 自动失控数值和倒计时仅供测试样品调试；把样品放回背包或换成正常装备后停止刷新。需要主动查数值时仍可使用 OP 指令 `status`。
- `trigger` 需要正确持有或穿戴对应系列的完好超载样品；0 级对照样品应被拒绝。
- 区域与召唤系列在显现阶段使用 `trigger` 时，预兆出现在面朝方向 4 格处；异化、封缄出现在自身脚下。自身型系列的视觉始终随身。实际行动按公共规则选落点。
- 附执、孕生的显现阶段需要存活的猎物，请先使用 `target` 生成靶子；没有猎物时不召唤。猎物死亡或离开当前维度，相关召唤物会消散。
- 需要验收真实扣血、饥饿和护甲受击时切到生存；创造模式可能免疫这些代价。
- `reset/cleanup` 不清除已经施加的原版药水状态。每轮可手动运行 `/effect clear @s`。
- `cleanup` 的实体范围为自己周围 64 格；区域替换和召唤数量检查范围为 48 格。不要跨很远的距离同时制造多组样品。

## 3. 建议的逐项操作

### A. 快速看预兆与显化

以天谴为例：

```mcfunction
/esotericism_tinker stigmata_test reset
/effect clear @s
/esotericism_tinker stigmata_test item judgement 3 2 sword
/esotericism_tinker stigmata_test trigger judgement
```

把刚发放的剑拿在主手后再运行最后一条。先站在圈内观察一次伤害，再 reset 并重来，在倒计时结束前走出 2.5 格半径的圈，确认可以躲开。

按下表依次替换 `family`，每个系列分别检查阶段 1、2、3。为看区域伤害，确保靶子或自己实际站在圈内。

### B. 验证真实积累与处理方式

1. `reset`，只装备当前样品，其他测试护甲卸下，副手清空。
2. 用剑攻击靶子；用弓射击靶子；用镐正常挖掘；或仅戴头盔后在生存模式用 `hit`。
3. 观察失控上升与 70 点预兆，确认不是每次攻击直接生成区域或实体。
4. 按该系列的平复方法处理，确认低于 40 点时取消预兆。对于需要提前停手的系列，也在失控 40–60 时开始处理一次。
5. 再故意不处理，确认显化、35 点回落和 6 秒冷却。
6. 在预兆时切槽，确认没有立即归零；把样品放背包后观察每秒 −10。
7. 用 degree 0 再试一次，确认攻击、挖掘、受击都不会产生新失控。

`trigger` 只验证预兆与显化，不验证命中、饥饿、经验、耐久或实际受击路径。以上真实操作必须另测。

### C. 单独验收接近触发的异象

拿着天谴封缄的超载样品，运行：

```mcfunction
/esotericism_tinker stigmata_test reset
/esotericism_tinker stigmata_test pressure judgement 55
```

保持装备、暂不行动，观察稀疏的头顶电光，随后变得更频繁、出现低声雷击音色，再进入正式聚电预兆，最后一秒电光加密、声音加强并爆发。天谴封缄每秒自主 +2，所以这一轮无需攻击靶子；`trigger` 会跳过接近触发的阶段，不能代替本项。

分别用第一人称和第三人称查看：近身粒子应能察觉但不挡准星，地面范围标记固定、头顶逐渐聚电；走远后区域爆发仍留在原地。换成吞灭等自身型系列后，预兆期间近身异象随人移动，实际爆发也发生在身边；没有可供走出躲避的地面预兆圈。

用正常超载装备复查相同表现，确认只有粒子和声音，没有数值或文字倒计时。测试样品显示精确状态属于调试功能。

